### P1 · 真·OBS 插件形态

| 项 | 内容 |
|---|---|
| 为什么 | 现在用户要手动改 OBS 的"推流服务器/密钥"；插件形态是"工具菜单点一下就出流"，这是**用户最容易察觉的体验差异** |
| 做法 | 写一个 `obs_register_output_s` 插件（`douy-phone-output.dll`），内部复用现有 `DOUY.Pc` 的 `RtmpServer`/`UsbBridge` 逻辑（C++/CLI 不可行 → 两个方案见下） |
| 方案 A（推荐） | 插件只做"薄壳"：注册一个 OBS 输出类型，把 OBS 的编码码流通过 **本机 RTMP** 或 **命名管道** 交给现有的 `DOUY.Pc.exe` 后台进程。好处：C# 逻辑不动，插件 C++ 只写 300 行 |
| 方案 B | 全 C++ 重写媒体/网络层（对齐原版形态），成本 5–8 倍 |
| 构建 | 需要 OBS SDK + MSVC → 走 `windows-latest` runner（GitHub Actions 可出 dll） |
| 工作量 | 方案 A：2–3 天（含 CI 出包 + 本机 OBS 验证） |
| 需要你定 | 走 A 还是 B |

## 4. 你现在就能做的三件小事（不用等我）

1. **把 `FXLicense.mm` 里的公钥换成你自己的**（我这次为了让你能立刻测，填的是本机测试密钥）；
   命令：`php server/bin/douyctl.php key:gen --force`，把输出公钥粘进去，重编 iOS。
2. **改服务地址**：`kFXDefaultBaseURL`（或运行时 `NSUserDefaults` 的 `FXLicenseBaseURL`）。
3. **改套餐收款码**：`douyctl plan:add --days=30 --price=68 --qr=https://<你的收款码>`（必须 HTTPS）。

## 5. 风险登记（我已知的坑）

| 风险 | 影响 | 缓解 |
|---|---|---|
| Secure Enclave 在注入进程不可用 | 授权签不出来 | 已回落 Keychain 软件密钥；(b) 真机确认后若不可用，就走软件密钥（安全性略降但仍可用） |
| 宿主 App 限制后台监听 28767 | USB 模式不可用 | 备用方案：改走局域网 RTMP（用户可切模式） |
| iOS 编译报错（16 个文件、无本地编译器） | 延迟 1–3 轮 | CI 快速迭代；我按日志改 |
| 抖音/快手等宿主对采集格式有硬要求 | 画面替换后花屏/黑屏 | 按宿主 buffer 尺寸与格式出帧；必要时加 vImage 缩放/格式转换 |
| MySQL 版本差异（你线上可能 8.0） | 建表语句兼容性 | schema 用的是 5.7/8.0 通用语法；8.0 也跑过语法检查 |
